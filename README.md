# Library System in Java

This repository contains a **basic library management system** developed in **Java**, as part of a school project for the subject related to Object-Oriented Programming.
The application works via **console** and uses a **menu system** to manage the different elements of a library.

---

## Project objective
- Apply **Object-Oriented Programming (OOP)** concepts.
- Model a real-world system using classes, attributes, and relationships.
- Implement an interactive console-based menu.
- Manage entities such as users, publications, and loans.
  

## Technologies used
- **Java**
- **IDE:** NetBeans
- **Console input and output**
  

## System functionalities
The system allows to:
- Create a library
- Create and list librarians
- Create and list users
- Create and list publications
- Register and list loans
- Create and list service students
- Display general information about the library


## Project Structure
The project is composed of classes that represent the main elements of the system, such as:
- Biblioteca
- Persona
- Bibliotecario
- Usuario
- Publicación
- Préstamo
- Alumno de Servicio
##### In addition, it includes a Main class that contains the menu implementation and the execution of the system.
